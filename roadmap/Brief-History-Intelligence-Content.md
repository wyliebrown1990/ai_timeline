## Glossary Terms

### Brain Structures
| Term | Category | Short Definition |
|------|----------|------------------|
| Basal Ganglia | model_architecture | Ancient brain structures involved in reinforcement learning, action selection, and habit formation |
| Neocortex | model_architecture | Six-layered outer brain region in mammals enabling sensory processing, prediction, and abstract thought |
| Hippocampus | model_architecture | Brain region essential for episodic memory formation and spatial navigation |
| Prefrontal Cortex | model_architecture | Front brain region responsible for executive functions, planning, and decision-making |
| Granular Prefrontal Cortex | model_architecture | Primate-specific PFC regions with granular layer 4, enabling abstract reasoning |
| Agranular Prefrontal Cortex | model_architecture | Older PFC regions without granular layer, found in all mammals |
| Thalamus | model_architecture | Brain relay station connecting sensory inputs to cortex |
| Amygdala | model_architecture | Brain region processing emotions, especially fear and threat detection |
| Striatum | model_architecture | Part of basal ganglia receiving dopamine signals for reward learning |
| Cerebellum | model_architecture | Brain region for motor coordination and timing, contains more neurons than rest of brain |

### Learning Mechanisms
| Term | Category | Short Definition |
|------|----------|------------------|
| Reinforcement Learning | core_concept | Learning paradigm where agents learn through rewards and punishments |
| Temporal Difference Learning | technical_term | RL algorithm that learns from differences between successive predictions |
| Prediction Error | core_concept | Difference between expected and actual outcomes, drives learning |
| Dopamine Prediction Error | technical_term | Dopamine neurons signal reward prediction errors, key to reinforcement learning |
| Classical Conditioning | core_concept | Learning where neutral stimulus becomes associated with a response (Pavlovian) |
| Operant Conditioning | core_concept | Learning where behaviors are modified by consequences (rewards/punishments) |
| Hebbian Learning | technical_term | Neurons that fire together wire together; basis of associative learning |
| Credit Assignment Problem | technical_term | Challenge of determining which actions led to delayed rewards |
| Actor-Critic Architecture | model_architecture | RL approach with separate policy (actor) and value (critic) networks |
| Model-Based Learning | core_concept | Learning that builds internal models of the environment |
| Model-Free Learning | core_concept | Learning directly from experience without explicit world models |

### Evolutionary Concepts
| Term | Category | Short Definition |
|------|----------|------------------|
| Cambrian Explosion | core_concept | Rapid diversification of animal life ~530 million years ago |
| Bilateral Symmetry | technical_term | Body plan with left-right symmetry, enabling directed movement |
| Triune Brain | core_concept | MacLean's theory of three evolutionary brain layers (reptilian, limbic, neocortex) |
| Encephalization Quotient | technical_term | Measure of brain size relative to body size across species |
| Cortical Columns | model_architecture | Vertical units of neurons in neocortex that process similar information |
| Theory of Mind | core_concept | Ability to understand that others have beliefs, desires, and intentions |
| Social Brain Hypothesis | core_concept | Theory that primate brains evolved for managing complex social relationships |
| Recursive Grammar | core_concept | Linguistic structure allowing sentences within sentences, unique to humans |

### Computational Concepts
| Term | Category | Short Definition |
|------|----------|------------------|
| Generative Model | model_architecture | Model that learns to generate data by modeling underlying distributions |
| Predictive Processing | core_concept | Theory that brains constantly predict sensory inputs and learn from errors |
| Free Energy Principle | technical_term | Framework proposing organisms minimize surprise through prediction |
| Hierarchical Predictive Coding | model_architecture | Brain architecture with layers making and correcting predictions |
| World Model | core_concept | Internal representation of the environment used for planning and prediction |
| Sensory-Motor Loop | technical_term | Cycle of sensing, processing, and acting that defines agent behavior |
| Value Function | technical_term | Function estimating expected future rewards from a state |
| Policy | technical_term | Mapping from states to actions that defines agent behavior |
