# Content Gaps Playbook

## Default lane

Always `propose`.

## Action

- generate a brief, not a draft
- include target keyword
- include thesis / angle
- include the entity-graph link inventory
- include relevant recent news hooks if they sharpen the angle
- route the brief to `/AIBlogDraft` when a full draft is wanted

## Hard refusals

- do not propose content that duplicates an existing entity page
- if the right answer is "fix the entity page," say that instead of drafting a blog post
- if the query is too vague to map to a strong thesis, downgrade to `human_only`
